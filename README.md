# Trade Learn — legal and support pages

Privacy policy, terms, account deletion and support for the Trade Learn Android
app (`com.tradelearn.app`), served by GitHub Pages at
<https://gauravkumarcs1988.github.io/tradelearn-legal/>.

Edit the copy in `build_pages.py` and re-run it — the `.html` files are
generated, not hand-edited:

```bash
python build_pages.py
```
